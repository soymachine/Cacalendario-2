Guía de build

Los dos procesos que usamos: subir una versión de verdad a producción / TestFlight, y compilar una build para probar en tu iPhone en local. Marca cada paso según lo vayas haciendo — queda guardado en este navegador.

Producción → llega a testers/App Store Desarrollo → solo tu iPhone, con Metro

Producción → TestFlight

0/6

Compila con las credenciales reales, sube el build a App Store Connect y ponlo delante de tus testers.

  1. Verifica que app.json está limpio

    No debe haber diferencias — expo-notifications tiene que seguir en plugins. Si algo aparece, es el workaround temporal de firma; deshazlo antes de seguir.

    cd mobile git diff app.json

  2. Compila la build de producción

    EAS reutiliza el certificado y el perfil ya guardados — no debería pedir login de Apple. 10-20 min.

    eas build --platform ios --profile production

  3. Súbela a App Store Connect

    Aquí puedes usar tu propia Apple ID (contraseña específica de app) — subir builds es acceso de App Store Connect, no del Developer Portal restringido.

    eas submit --platform ios --latest

  4. Espera el procesado de Apple

    App Store Connect → tu app → TestFlight → iOS Builds. De "Processing" a listo: 15 min – 2 h. Si repregunta por Export Compliance, es exento (solo HTTPS estándar).

  5. Añade el build al grupo de Internal Testing

    TestFlight → Internal Testing → crea o reutiliza un grupo → Add Testers (marca a la gente de Users and Access) → asocia este build. No pasa por revisión de Apple.

  6. El tester instala desde TestFlight

    App TestFlight desde la App Store → acepta la invitación que llega a su Apple ID → Install.

Desarrollo → tu iPhone

0/5

Un dev client instalado en tu propio iPhone, conectado a Metro en tu Mac — para iterar rápido sin pasar por App Store Connect.

  1. Registra tu iPhone (solo la primera vez)

    Abre el enlace/QR resultante desde Safari en el propio iPhone para registrar el UDID.

    cd mobile eas device:create

  2. Compila el dev client

    Build en la nube con las credenciales ya guardadas — capabilities completas (push incluido), sin líos de firma local. 10-20 min.

    eas build --profile development --platform ios

  3. Instala desde el QR

    Al terminar, la terminal (y expo.dev) dan un QR — escanéalo con la Cámara del iPhone e instala. Como un Ad Hoc, sin TestFlight.

  4. Arranca Metro

    Déjalo corriendo en una terminal mientras trabajas — es lo que sirve el JS en caliente.

    npx expo start --dev-client

  5. Abre la app en el iPhone

    Se conecta sola a Metro (misma WiFi que el Mac). Cada guardado recarga al instante.

Referencia rápida — para el detalle completo de cada paso (certificados, provisioning, TestFlight externo, solución de problemas), ver mobile/README.md en el repo.
